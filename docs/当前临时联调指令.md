# 当前临时联调指令

以下指令为当前临时联调指令，仅用于链路和功能验证，后续以产品正式指令清单为准。

## 主题切换

| 指令名称 | 指令参数 | 参数类型 | 必填 | 参数取值范围 | 参数示例 |
| --- | --- | --- | --- | --- | --- |
| 主题切换 | 主题名称 | 字符串 | 是 | 综合态势；综合安防；便捷通行；资产管理；设施管理；能源管理；办公会议；网络体验 | 综合安防 |

```json
[
  {
    "action": "主题切换",
    "params": {
      "主题名称": "综合安防"
    }
  }
]
```

## 环境时间效果

| 指令名称 | 指令参数 | 参数类型 | 必填 | 参数取值范围 | 参数示例 |
| --- | --- | --- | --- | --- | --- |
| 环境时间效果 | 时间 | 字符串 | 是 | `00:00`–`23:59`，严格 `HH:mm` | `20:00` |

时间必须为严格 `HH:mm` 字符串。

```json
[
  {
    "action": "环境时间效果",
    "params": {
      "时间": "20:00"
    }
  }
]
```

## 主题切换后设置环境

一次 HTTP 请求可以通过同一个 JSON 数组发送多条指令，当前前端按照数组原始顺序处理。

```json
[
  {
    "action": "主题切换",
    "params": {
      "主题名称": "综合安防"
    }
  },
  {
    "action": "环境气象效果",
    "params": {
      "天气": "雾"
    }
  },
  {
    "action": "环境季节效果",
    "params": {
      "季节": "冬季"
    }
  },
  {
    "action": "环境时间效果",
    "params": {
      "时间": "20:00"
    }
  }
]
```

当前仅保证按数组顺序发起处理，不表示等待上一条 UE 动画执行完成后再处理下一条。
