# 练秋湖 IOC AI 执行器部署与配置说明

## 1. 仓库与运行环境

GitHub：<https://github.com/StrawHat-Kid/lianqiuhu-ioc-executor>

- 仓库：Private
- 部署分支：`master`
- 开发分支：`develop`
- Node.js：`>=18`
- 入口：`src/server.js`
- 无需 build

启动：

```bash
npm install
npm start
```

测试：

```bash
npm test
```

## 2. `.env` 配置

当前 `.env` 随 Private 仓库维护，其中包含 MQTT 连接凭据；不要在文档中回显真实凭据。

| 变量名 | 作用 | 默认值/约束 |
| --- | --- | --- |
| `PORT` | HTTP 服务端口 | 默认 `8008` |
| `MQTT_URL` | MQTT Broker 地址 | 必填，必须为 `mqtts://` |
| `MQTT_USERNAME` | MQTT 用户名 | 必填 |
| `MQTT_PASSWORD` | MQTT 密码 | 必填 |
| `MQTT_TOPIC` | MQTT 发布 Topic | 必填 |
| `MQTT_QOS` | MQTT QoS | 必填，仅接受 `0` |
| `MQTT_RETAIN` | retain | 必填，仅接受 `false` |

`queueQoSZero` 不是环境变量，代码固定为 `false`。

## 3. HTTP 接口

- 默认端口：`8008`
- `GET /health`
- `POST /api/commands`

本机访问示例：`http://127.0.0.1:8008`。源码使用 `listen(config.port)`，未显式指定 host。

`POST /api/commands` 使用 `Content-Type: application/json`：

```json
[
  {
    "action": "指令名称",
    "params": {}
  }
]
```

- 顶层必须为非空数组。
- `action` 必须为非空字符串。
- `params` 如存在必须为普通对象。
- 完整数组一次 MQTT publish。
- Node 不转换业务参数。

| HTTP 状态 | 含义 |
| --- | --- |
| 200 | MQTT publish 成功 |
| 400 | JSON 或指令基础格式错误 |
| 503 | MQTT 当前未连接 |
| 500 | MQTT publish 执行失败 |

## 4. MQTT 配置

- Node → Broker：`mqtts://`
- 当前联调使用 EMQX Cloud。
- `MQTT_TOPIC`：`lianqiuhu/ioc/demo/commands`（当前联调配置，正式环境以后续配置为准）
- QoS：`0`
- retain：`false`
- `queueQoSZero`：`false`
- `reconnectPeriod`：`1000ms`

- MQTT 未连接时，HTTP 指令返回 503。
- 不缓存断线期间的控制指令。
- 恢复连接后不补发旧 QoS 0 指令。

## 5. 健康检查

```text
GET /health
```

MQTT 正常：

```json
{"ok":true,"mqttConnected":true,"status":"ready"}
```

MQTT 未连接：

```json
{"ok":true,"mqttConnected":false,"status":"mqtt_unavailable"}
```

`/health` 始终返回 HTTP 200，MQTT 状态以 `mqttConnected` 和 `status` 为准。
